# Aeryvex Pro

This repository is the **main home for the Aeryvex Pro Godot 3.x game**.

## Current state

The latest local development snapshot is **Go 32 — Battlefield Overhaul**. The game source has not yet been uploaded into this repository. Upload the **contents** of `AeryvexPro_3D_Godot/` (including `project.godot`, `scripts/`, `scenes/`, `tests/`, and `tools/`) to the repository root. Do **not** upload only the ZIP file.

## Running

Open `project.godot` in Godot 3.5/3.6 and run the project. Use `bash tools/run_all_checks.sh` once sources are present to run local checks.

## Project priorities

1. Establish a launching, playable Godot game and run engine tests.
2. Improve full character models, skeletal animation, environments, effects, and audio.
3. Complete Galactic Arena, Duel, Galactic Fronts, campaign, and progression.
4. Test and export release builds. Commercial distribution requires rights-cleared original content.

No feature should be called verified solely because source-structure checks pass.
