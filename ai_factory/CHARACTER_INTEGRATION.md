## Workflow now working end to end

Approved reference → Meshy or uploaded GLB → Godot import and inspection (renders beside the reference) → human approval or rejection → animation-mapping verification → player binding → rebuilt game with an engine character QA stage → native Linux export re-tested from the relocated executable.

| Step | Module | Verified by |
|---|---|---|
| Lock exact approved reference (never replaced) | `character_studio.lock_reference` | `test_character_studio.ReferenceLockTests` |
| Meshy Image-to-3D from the locked bytes, paid-credit authorization | `character_studio.meshy_generate`, `meshy_bridge` | offline HTTP stubs (no live request) |
| Meshy auto-rig + basic animations merged into one GLB | `meshy_rig`/`meshy_fetch`, `glb_tools.merge_animations` | stubs + `test_glb_tools` |
| Upload GLB / merge same-rig clip files | `add_upload`, `merge_candidate_animations` | unit + browser E2E |
| Real Godot inspection: bones, clips, clip-moves-skeleton, renders | `character_inspect` | engine test + browser E2E |
| Stage with provenance; approve (requires inspection) / reject with reason (unbinds) | `stage_candidate`, `decide` | `DecisionTests`, browser E2E |
| Bind with height fit and facing correction | `character_studio.bind` → `bind_player` | engine test |
| Animation state machine | `templates/rpg_3d/actor.gd` | `character_scenario.gd` (31 checks) |
| Character QA in game build and in native export | `core.test`, `native.export_linux` | `character`, `relocated_character_scenario` |
| Gameplay screenshots of the built game | `preview.capture` | browser E2E, CLI |
| One interface | `ui/studio.js`, `app.py` routes, `factory character …` CLI | `browser_character_e2e.py` |

Animation states: `idle, walk, run, jump, fall, land, attack, hurt, death, cinematic_*`. Priority order is death > cinematic > hurt > attack > airborne > landing > locomotion. The machine crossfades between clips, loops locomotion clips, holds the death pose and revives to idle. Fallbacks are run → walk, fall → jump and land → idle.

## Not done / needs you

- **Live Meshy**: unreachable from the build sandbox, and no key was available. Image-to-3D, rigging and animation-library calls are implemented against Meshy's documented endpoints and tested only with stubs. The first real run spends credits; check the result fields and report any mismatch.
- **Your approved characters**: no reference images for the ten rulers are in the repository (`ten_rulers_approved_lineup.png` is referenced but absent). Lock them in the Character Studio yourself; the factory will never invent or substitute them.
- Meshy GLBs that declare glTF extensions are rejected by the strict intake validator.
- No cross-skeleton retargeting, motion generation, Story/Cinematic/Audio directors, or wrestling/fighting systems. The app's "Factory components" panel lists the status of each of the 10 components.
